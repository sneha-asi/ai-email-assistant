# AI Email Assistant — frontend

React + Vite + TypeScript + Tailwind + shadcn/ui client for the FastAPI backend in
`../backend`. Routes: `/` (landing page), `/app` (the working inbox) and `/demo`
(guided walkthrough).

```bash
npm install
npm run dev      # http://localhost:8080 (expects the backend on :8000, or set VITE_API_BASE)
npm run build    # production build
```

See the [root README](../README.md) for setup, modes and the API.
